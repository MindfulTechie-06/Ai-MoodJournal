## 🌟 Overview
**AI Mood Journal** is a smart journaling app that combines the simplicity of writing with the power of artificial intelligence.  
It allows users to **log their daily thoughts**, and then uses **AI sentiment analysis** to identify emotional tone — positive, neutral, or negative — helping users **track and understand their mental well-being** over time.

This project was built in **24 hours** during a hackathon and hosted using **Streamlit** for an intuitive and interactive experience.

---

## 🚀 Features
✅ **AI-Powered Mood Detection** — Instantly analyzes the emotion behind your journal entry  
✅ **Daily Journal Logging** — Write your thoughts safely and privately  
✅ **Mood History Dashboard** — View past entries and visualize trends  
✅ **Encouraging Feedback** — Get uplifting responses based on your detected mood  
✅ **Lightweight & Fast** — Streamlit-powered frontend for seamless use

## 🛠️ Installation
Follow these simple steps to set up and run the project locally 👇

```bash
# Clone the repository
git clone https://github.com/your-username/ai-mood-journal.git

# Navigate to the project folder
cd ai-mood-journal

# Install required dependencies
pip install -r requirements.txt

# Run the Streamlit app
python -m streamlit run app.py
